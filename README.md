Once the project is opened in Visual Studio, running the program will take you to the page showing Time Entry data, along with the option to access the Modal to add a new time entry

Approach - I approached this project with the idea that I should work on filling in the data and display in a table first, then work on the form for adding a new entry and writing the new entry to the form and displaying with the new time entry. This would allow me to fill in the rest of the functionality, such as the sort filter and the validations

Improvement - Sorting by any column would be a pretty nice, and probably simple, addition, but I'll keep to the specifications with name and date. Perhaps give the page slightly more style and color, but right now I think the inputs and displays are very well spaced how I have it and clearly readable.
